# Layout Corrector v1.14 ⌨️✨

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Platform: Windows](https://img.shields.io/badge/Platform-Windows-0078D6.svg)](https://www.microsoft.com/windows)
[![Python: 3.10+](https://img.shields.io/badge/Python-3.10%2B-brightgreen.svg)](https://www.python.org/)

**Layout Corrector** — це швидкий, надійний та сучасний інструмент для виправлення тексту, випадково набраного не в тій розкладці клавіатури (наприклад, `ghbdtn` ⇄ `привіт`), швидкої зміни регістру літер та попереднього перегляду перекладу у спливаючому вікні.

---

## 🚀 Що нового у версії 1.14 (Великий редизайн UI v2)

- 🎨 **Новий інтерфейс Material 3 Expressive:**
  - Глибока графітова палітра з неоновими акцентами («Neon Graphite»).
  - Інтегровано сучасний український шрифт **MacPaw Fixel** (Display та Text).
  - Зручна бічна панель навігації замість застарілих вкладок.
  - Повністю симетричний редактор розкладок у пропорційних юнітах (Backspace, Shift, Tab та Caps Lock не обрізаються).
  - Інтерактивні картки гарячих клавіш із безпечним режимом запису нової комбінації в один клік.
- 📸 **Розумне збереження буфера обміну:**
  - Виправлено втрату зображень: якщо в буфері лежав скріншот, скопійований файл або формати з інших програм, після натискання гарячої клавіші вони автоматично відновлюються у повному обсязі!
  - Тимчасовий текст не засмічує історію Windows Clipboard (`Win + V`) завдяки спеціальним системним прапорцям.
- 💬 **Оновлений попап та трей:**
  - Спливаюче вікно перекладу зі смужкою таймера, яка автоматично ставиться на паузу при наведенні курсора миші.
  - Закреслений оригінал + великий виправлений результат + кнопка копіювання в буфер.
  - Напівпрозоре заокруглене меню в системному треї.
- 🛡️ **Безпека та стабільність:**
  - Усунено залипання модифікаторів (Shift/Ctrl) при надшвидкому натисканні.
  - Захист від блокувань (таймаут безпеки 5 с) та оптимізований `SendInput`.
  - Циклічна зміна регістру (Gboard style: `Кожне Слово` → `ВСІ ВЕЛИКІ` → `всі малі`) з підтримкою багаторядкового тексту.

Детальний список усіх змін дивіться у [CHANGELOG.md](CHANGELOG.md).

## ⌨️ Стандартні гарячі клавіші

| Дія | Комбінація за замовчуванням | Опис |
|---|---|---|
| **Виправити на місці** | `Ctrl + Alt + Z` (або `Ctrl + Shift + Z`) | Виділіть текст — він миттєво конвертується прямо у вашому редакторі |
| **Переклад у попапі** | `Ctrl + Alt + X` (або `Ctrl + Shift + X`) | Показує правильний варіант біля курсора без заміни в тексті |
| **Зміна регістру** | `Ctrl + Alt + C` (або `Ctrl + Shift + C`) | Циклічно змінює регістр виділеного тексту |

*Комбінації повністю налаштовуються у вікні «Гарячі клавіші та опції».*

## 🛠️ Запуск із вихідного коду

### Вимоги
- Windows 10/11
- Python 3.10+
- PyQt6, pyperclip, gdown, pyinstaller

### Швидкий старт
1. Склонуйте репозиторій:
   ```bash
   git clone https://github.com/doctorzdes-art/layout-corrector.git
   cd layout-corrector
   ```
2. Запустіть готовий скрипт (створить віртуальне середовище, встановить залежності та запустить додаток):
   ```cmd
   run.bat
   ```

### Збірка `.exe` через PyInstaller
```cmd
build.bat
```
Скрипт збере автономний бінарник із вшитими шрифтами, фігурами, іконками та стилями у папку `dist/`.
