# Layout Corrector v1.13 ⌨️🔄

**Layout Corrector** — це зручний та легкий інструмент для автоматичної та ручної корекції розкладки клавіатури (наприклад, з виправлення тексту `ghbdtn` -> `привіт`), виправлення регістру літер та швидкої перекладацької взаємодії.

---

## ✨ Основні можливості (v1.13)

- 🔄 **Миттєве виправлення розкладки (Ctrl + Alt + Z)**:
  - Автоматично конвертує помилково набраний текст у потрібну мову (UA ↔ EN ↔ RU).
  - Підтримує автоматичну зміну системної мови введення після виправлення.
- 🔠 **Зміна регістру (Ctrl + Alt + C)**:
  - Швидка зміна РЕГІСТРУ виділеного тексту (ВЕРХНІЙ ↔ нижній ↔ З Великої Літери).
- 💬 **Вспливаюче вікно корекції (Ctrl + Alt + X)**:
  - Відображає результат перекладу у зручному спливаючому вікні без автоматичної заміни в документі.
- ⚙️ **Гнучкі налаштування**:
  - Налаштування гарячих клавіш для кожної дії.
  - Автозапуск разом із Windows.
  - Зручне меню в системному треї.
  - Кастомні таблиці символів та підтримка спецсимволів/діакритики.

## 🛠️ Встановлення та запуск із сирцевого коду

### Вимоги
- Python 3.10+
- PyQt6

### Запуск (Windows)

1. Клонувати репозиторій:
   ```bash
   git clone https://github.com/YOUR_USERNAME/layout_switcher_app.git
   cd layout_switcher_app
   ```

2. Створити та активувати віртуальне середовище:
   ```bash
   python -m venv venv
   .\venv\Scripts\activate
   ```

3. Встановити залежності:
   ```bash
   pip install -r requirements.txt
   ```

4. Запустити застосунок:
   ```bash
   python main.py
   ```

## 💻 Портування на macOS

Цей репозиторій містить вихідний код версії для Windows. Модуль обробки гарячих клавіш (`hotkey_listener.py`) використовує системні виклики Windows API (`ctypes.windll.user32`). 

Для збірки аналога під macOS:
- Модуль `hotkey_listener.py` потребує адаптації під macOS API (наприклад, через Quartz Event Taps, CoreGraphics або `pynput`).
- Модулі UI (`ui_settings.py`, `ui_popup.py`), логіка конверсії (`translator.py`) та конфігурація (`config.py`) є повністю кросплатформними.
